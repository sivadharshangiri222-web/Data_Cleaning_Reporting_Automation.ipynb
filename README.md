# 📊 Data Cleaning & Reporting Automation

## 📌 Project Overview

Data Cleaning & Reporting Automation is a Python-based data analytics project that automates the process of cleaning raw sales data, analyzing the cleaned dataset, generating visualizations, and creating an Excel-based business report.

The system identifies common data-quality issues such as missing values, duplicate records, inconsistent text values, and incorrect data formats. It automatically processes the dataset and generates a structured analytical report.

---

## 🎯 Objectives

- Automate data cleaning and preprocessing
- Handle missing values
- Detect and remove duplicate records
- Standardize inconsistent data
- Perform automated sales analysis
- Generate business KPIs
- Create data visualizations
- Generate an automated Excel report
- Reduce repetitive manual reporting work
